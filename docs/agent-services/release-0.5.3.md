# FMG CLI and Skills 0.5.3

Both Skill entrypoints and individual/batch email references now explicitly
preserve selected fixed PR templates. LIMINAL uses liminal-outreach and only
its five declared variables; no unsolicited generic-template substitution,
rewriting, disclaimers, duplicated Internal Test markers or signature changes.
Evidence requirements apply to personalized variable values. Missing evidence
requires clarification/incomplete drafts, not invented values or template swaps.
Explicit send approval is unchanged.

Upgrade with `fmg upgrade --latest --skills` and reread both Skills in the active
Agent conversation. No server deployment, template body change or email sending.
