# 来源与许可边界

`steam-entry.svg` 复用本项目 release-v5 设计包的 `assets/states/empty-search.svg`，用于 P1 Steam 入口；不是截图裁切或真实身份图片。

本包没有附带第三方字体、购买素材库或官方平台 Logo，不承诺商标可注册、独家版权或已完成法律审查。

## 原生矢量

品牌狐狸、几何 OUTPUT 字标、状态/装饰/占位图与 47 个通用图标为本项目用几何路径编写的 SVG。不是对截图的自动描摹，不是 SF Symbols 导出，也没有调用外部图标库。源 SVG 可编辑；PNG 由这些 SVG 渲染。

## AI 场景背景

两张背景由内置图像生成工具生成，以最终 P4 页面仅作风格参考；保留原始场景像素和生成记录。交付使用仍受生成服务适用条款约束；上线前检查潜在品牌相似性及目标渠道要求。本说明不构成可商用、无侵权或独占权的保证。

`provenance/backgrounds-receipt.json` 包含生成提示词、原输出尺寸、SHA-256 和构图说明；其中原设备绝对路径仅用于追溯，不是运行依赖。

## 参考图

`references/screens` 是本轮确定性生成的 OUTPUT 页面设计参考，不是可复用的真实游戏封面、KOL 肖像或平台数据来源。不要把整页图、其中的封面或头像切出用于生产身份展示。

## 系统字体与图标

仅通过系统 API 使用 macOS 系统字体，不随包分发 SF/PingFang 字体文件。可选替换为 SF Symbols 时，由开发确认各符号适用范围与系统可用性；本包本身不包含 SF Symbols 文件。

## 开发可做的事

在本项目内编辑源 SVG、调整 token、重新导出适配尺寸；真实游戏/创作者图片与平台 Logo 需要独立来源管理。技术可编辑性不等于对所有第三方名称、内容、字体或商标的授权。
