## Task path and state design

Library → search/filter/sort → compact current-record rows → Creator/Game detail/edit → return to same list. Match → choose existing search → filter recorded evidence/order → inspect candidates → mark explicit subset → name/save → reopen saved list or original query. No new obligatory wizard.

| State | Focus / primary action | Context and transition |
|---|---|---|
| Ready | List / open record | Compact toolbar and filtered total, original navigation |
| Choosing filter | Multi-choice panel / Apply | Cancel/Escape retains prior applied values; named presets and custom values remain accessible |
| Refreshing | Same list with local progress | Freeze relevant actions while stale, no focus/scroll takeover; old successful data retained and honestly labeled on failure |
| Empty/error | Clear filters or retry exact read | No guessed backend data, drafts and successful context retained |
| Saved-set draft | Marked subset/name / Save list | Clear local membership count, no outreach or send implication |
| Saving/uncertain | Submitted immutable name/IDs/request_id / reconcile or retry | Same query/body/key preserved; no silent second set, unrelated task remains guarded |
| Reopened set | Saved subset / view record or original search | Metadata count vs filtered total distinct, later candidates excluded; old query status/budgets retained |
