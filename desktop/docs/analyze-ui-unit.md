# Analyze desktop unit

Scope: desktop only; accepted Steam c57b66a, YouTube bc96c60, X/runtime5706ad7 and existing jobs APIs. No backend, contract, credentials, deployment or external-send changes.64692 is the coordinator-authorized isolated fixture; upstreams synthetic.

## Task path and hierarchy

Library → source import/binding where required → saved profile → explicit Analyze → retained task drawer → explicit View profile. Existing canonical YouTube and numeric X use reanalyze, including metadata-only profiles. Twitch/Instagram and unbound X remain manual. Steam import is source-only, not AI completion.

| State | Focus / primary action | Supporting content / disclosure |
| --- | --- | --- |
| No source | Steam URL / Import; YouTube URL / Bind channel | Manual entry stays accessible; selected UUID/revision fixed |
| Bound profile | Profile / Analyze | Canonical source visible at confirmation; provenance collapsed |
| Confirm | Selected target / Analyze | Short cost consequence; no automatic submit after binding |
| Queued/running | Actual stage | Close drawer retains task; no invented percent/ETA/cancel |
| Paused | Reason / Collection settings or explicit Resume | Existing profile and checkpoints retained |
| Failed | Local error / Retry if supported | Previous profile remains; retry produces a new job |
| Unknown write | Frozen request / Check same request | Same body/key within retention; no silently new intent |
| Complete | Result / View profile | No automatic navigation, scrolling or input replacement |

Source operations retain URL and explicit target. Successful import/binding updates the returned v2 record, not manual overrides. Navigation within mounted Library retains operation/drafts; connection changes fence old work. Profile opening is guarded against overwriting another editor. Advanced source/model evidence stays in named disclosures, while available AI observations and actual source coverage are readable without raw JSON.

## Exceptions and return paths

No cancel endpoint exists: Close only closes the drawer. Read errors preserve current content and support read retry. Mutation transport loss retains immutable key/body; credential change cannot replay into another workspace. Revision conflict requires a fresh selected record. Failed analysis never clears prior results. Polling is serialized/bounded; waiting_reason takes precedence over queued/running. System reduced-motion and keyboard controls remain usable. Back/Settings detours retain inputs rather than start a new request.

## Verification boundary

Each finite unit uses regression tests before implementation and one bounded review. Record targeted test results, real API/worker/DB and actual renderer writes separately from mocked component tests. Existing fixture identities are reused; first-binding success cannot be falsely claimed against an already-owned channel. Native Electron/IPC/Keychain/package and live provider permissions require separate evidence.
