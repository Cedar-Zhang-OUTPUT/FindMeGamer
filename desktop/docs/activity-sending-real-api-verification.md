Original Activity context and recipient snapshots are compared after the first scenario; all delivery snapshots remain immutable. The private0600 physical ledger (`private/p7-sending-RUN_UUID.json`) records only run/public IDs, stage, fixed error labels, route-family counts, SMTP event labels, MIME hashes/counts, explicit scenario interpretation and restoration status. Credentials, raw response bodies, raw emails, and MIME text never enter reports or console output. Failed setup and partial side effects remain in the ledger; there is no automatic resume or cleanup of business records.

Before acceptance, root must review and execute this single test under its lease, preserve the original outcome, inspect the sanitized ledger and confirm controls/queues on handback. Production-renderer, Electron/native, package and real mailbox delivery acceptance remain separate.
