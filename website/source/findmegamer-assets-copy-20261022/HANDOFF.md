# 给接手 Agent 的简报

## 任务边界

请使用本包的文案和素材，为 FindMeGamer 设计并实现官网。用户明确不需要本包提供网站原型；页面设计由你决定。用户希望使用 Three.js，具体效果由你设计，不能牺牲移动端、可访问性或安装入口的可用性。

品牌沿用 FindMeGamer 拼写。产品是给游戏开发者和发行团队使用的创作者研究与外联工具，不是给玩家找队友、接单撮合或保证推广效果的平台。

## 最重要的产品入口

唯一主转化动作：**复制短 Prompt 给用户自己的 Agent**。

- 入口内容使用 `copy/agent-entry.json`，不要另写一长段安装命令。
- 展示完整可选中的 Prompt；按钮复制纯文本，不包含 Markdown 围栏。
- Prompt 让 Agent 先读取公开安装 README，不让用户自己按系统挑安装包。
- 旁边提供“阅读安装指南”作为辅助入口。
- 复制成功：仅在剪贴板写入真正成功后显示“已复制，粘贴给你的 Agent”。不能显示“已安装”。
- 复制失败：保留可选文本，提示手动复制。HTTP 环境、权限拒绝等不能导致入口不可用。
- 本包未提供用户授权申请渠道；不要虚构申请表、免费试用、登录入口或客服地址。
- 缺 token 时必须是“已安装，待授权”，不是“可以开始使用”。
- 安装与业务调用分开：不自动搜索、邮箱补强或发测试邮件。

## 内容选择

`home.*.md` 是可组合的文案库，不是固定的页面线框。优先保留主标题、产品解释、三步安装、能力、边界、FAQ、最终 CTA。篇幅紧张时删减备选文案，不把全文堆到首页。

主张：找匹配，而不是堆名单；让 Agent 做研究，人保留判断和发送决定。

不要声称与平台有官方合作。YouTube、Twitch、X、Steam 只作为文字提及；未提供其商标图片。不要为装饰图加入虚构统计或伪造实时执行状态。

## 素材与 Three.js

两张 PNG 可作为主视觉/辅助视觉或 WebGL 不可用时的静态素材。它们不是可旋转 3D 模型，也没有深度图；不要把 PNG 的平面旋转宣传成真实三维交互。真实 Three.js 几何与材质由你实现。可借用轨道、节点、选择性连接的意象，不必复制整张渲染图。

插画统一为暖白、钴蓝、浅薄荷色。此为素材自身配色，不限定最终网页设计。图标统一 24px viewBox、1.7px 描边、圆角端点，以 currentColor 继承颜色。现有 App 图标仅供品牌沿用判断，不强制塞进导航。

## README 上线前修订清单（重要）

目前候选公开地址：

https://raw.githubusercontent.com/Cedar-Zhang-OUTPUT/FindMeGamer/cli/docs/agent-services/AGENT-INSTALL.md

2026-10-22 直接 HTTP 读取成功，但指南仍指向 0.8.1，包含过期业务邮箱/模板描述。它是安装 README 的现有落点，并非本次已修订的发布件。请在有发布权限和用户授权后处理：

1. 确认当前 CLI 专用 release，更新指南及校验步骤；不能使用混有 macOS DMG 的通用 latest 逻辑。
2. 公共 onboarding 去掉特定客户/游戏的邮箱选择，业务场景另读安装后的最新 Skills 与服务目录。
3. 明确支持系统、所需 Agent 工具、token 获取流程、权限范围与成本边界。
4. 明确已有安装如何更新并保留配置，如何处理 Skills 重载。
5. 下载需 HTTPS、校验；禁止关闭 TLS 校验或泄露 token。
6. 无 token 的用户能够安装，但不能假装服务可用；实际授权渠道未确定前勿添加链接。
7. 匿名环境测试 README 与 release 可读、复制字符串无误，然后启用官网复制入口。

网站不要写死 CLI 版本，也不要镜像一份容易漂移的完整安装脚本。若后续建立官网 `/install/README.md`，在入口 JSON 内替换同一个文档 URL，并验证目标内容，不要先发布一个不存在的 URL。

## 交接验收

- 中英两版入口复制内容和 JSON 一致，URL 可访问且指南已修订。
- 键盘可操作；复制失败可手动选择；复制结果有可访问的状态反馈。
- JavaScript / WebGL 失败仍能阅读文案和获取安装 Prompt。
- 移动端不遮挡 CTA，减少动态效果偏好下不强制播放动画。
- 不接入现有生产发信或补强服务作为展示；不使用真实联系人。
- 发布前另行确认域名、隐私声明、条款、访问申请方式；本包没有捏造这些内容。
