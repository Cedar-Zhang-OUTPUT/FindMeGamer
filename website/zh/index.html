02 使用方式

给你的 Agent，多一项能力。

无需为了开始使用而切换到新的操作后台。复制一段短 Prompt，让 Agent 读取安装指南，把 FindMeGamer 接入你熟悉的工作流。

  1. 01

    复制 Prompt。

    发给具备终端和文件访问能力的 Agent。

  2. 02

    让 Agent 完成安装。

    按指南安装 CLI 和 Skill，并遵守当前环境的权限要求。

  3. 03

    完成授权，再提出任务。

    私下配置 FMG 访问令牌；确认游戏、平台和研究范围后再开始。

03 产品能力

从第一次匹配，到后续跟进。

  • 从游戏本身出发

    提供 Steam 游戏链接或明确的游戏介绍，用题材、玩法、氛围和期望的内容形式，为研究设定方向。

  • 发现相关创作者

    研究 YouTube、Twitch 和 X 上的游戏创作者。关注相关内容和可解释的匹配，而不只看粉丝规模。

  • 看懂为什么匹配

    把匹配理由与可供核对的证据放在一起。由团队判断，谁值得进入最终名单。

  • 补充公开商务联系方式

    为候选名单查找可获得的公开商务邮箱。找不到或无法独立核验时，保留真实的不确定性。

  • 准备有针对性的邀约

    明确发件邮箱和模板，审核正文与收件人，再确认发送。安装工具不等于授权联系任何人。

  • 跟进发送情况

    通过工作流查询任务进度、投递异常和邮箱监控情况。邮件服务器接受发送，不代表一定进入收件箱或获得回复。

04 任务示例

从一段清楚的 brief 开始。

安装并授权之后，研究从游戏和你们确认的范围开始。一段 brief 可以就这么短。

任务示例

“
为这款 Steam 游戏找 10 位适合的 YouTube 创作者：[Steam 链接]。优先寻找关注叙事类独立游戏的频道，列出匹配理由和可用证据。先不要补充邮箱，也不要发信。

此为任务示例。实际研究可能消耗服务额度，执行前先确认范围。

05 使用边界

Agent 做研究，决定权在你。

  • 01

    发信前审核。

    收件人和正文确认后，才进入发送流程。

  • 02

    凭证不进网页。

    通过私密方式授权，不在官网粘贴访问令牌。

  • 03

    结果如实呈现。

    联系方式缺失、结果未核验、上游服务错误，都不应被包装成「成功」。

06 常见问题

把问题讲清楚。

如果你缺少令牌或权限，请联系你的 FMG 管理员。

这是下载安装，还是网页应用？
主要入口是一段发给 Agent 的 Prompt。Agent 读取指南后安装 FindMeGamer CLI 和配套 Skill。官网负责介绍和分发，不是执行研究任务的工作台。
安装完就可以直接使用吗？
还需要 FMG 访问令牌及相应权限。没有令牌时，请联系你的 FMG 管理员；安装本身不会自动获得服务访问权。
支持哪些平台？
当前工作流包含 YouTube、Twitch、X 创作者研究，以及 Steam 游戏背景信息。实际可用能力受服务权限和上游可用性影响；提及平台不代表官方合作或背书。
每位创作者都能找到邮箱吗？
不能保证。公开商务联系方式补强是尽力查询，正常找不到也是合理结果。找到地址不代表已经验证身份、保证可投递，或获得联系许可。
Agent 会自动发信吗？
安装过程不会发信。外联需要另行确认发件邮箱、收件人和邮件正文，并授权执行发送流程。
「发送成功」意味着进入收件箱了吗？
不意味着。服务器接受、实际投递、进入收件箱、收到回复是不同结果。FindMeGamer 不保证回复或内容报道。
所有 Agent 和操作系统都能用吗？
当前指南面向具备终端和文件工具的 Codex，支持 macOS 和 Linux。其他环境需核对兼容性，不应宣传为全平台即装即用。
研究任务免费吗？
安装不授权付费调用。研究和邮箱补强可能消耗服务或上游额度，使用前请向管理员确认。当前不在官网文案中承诺价格或免费额度。
